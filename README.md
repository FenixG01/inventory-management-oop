# Stationery Store Inventory System - OOP & MVC

Final project for the Object-Oriented Programming course. This is an inventory management and employee access control system developed using the **MVC** architectural pattern, Object-Oriented Programming (OOP), and a relational database.

## 🛠️ Prerequisites (Technical Requirements)
To run this project on a new computer, you will need:
* **Python 3.10** or higher installed.
* **MySQL Server 8.0** (or higher) installed and running.
* Python MySQL connector library. Install it by opening your terminal and running:
  ```bash
  pip install mysql-connector-python
